# funding-dashboard

最早做的跨所资金费率表。后来功能都并进加密终端了，这个仓库基本空着，打开跑不起来。

现在看盘用这一页：[资金费率](https://crypto-funding-arbitrage.pages.dev/#/funding)  
源码在 [crypto-funding-arbitrage](https://github.com/shangchaovo/crypto-funding-arbitrage)。

当时只做了一件事：把各所永续的 funding rate 拉到同一张表里，方便找费率差，或者「现货多 + 永续空」去收资金费。后面才加上 8 小时折算、数据过期标记这些。

期权那页当时是另一个仓库：[crypto-options-analyzer](https://github.com/shangchaovo/crypto-options-analyzer)。

数据来自公开接口，随便看看就好，别当交易建议。
